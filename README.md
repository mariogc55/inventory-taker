# TiendaBarrioInventory
### Aplicación móvil, actualmente en fase de planteamiento y diseño

#### InventoryT es una aplicación móvil de gestión de inventario, ventas y gastos, pensada para microempresas colombianas (tiendas de barrio, minimercados), desarrollada como proyecto del curso de Computación Móvil. El objetivo es construir una herramienta nativa para Android que permita registrar productos, ventas y gastos, calcular ganancias en tiempo real y generar reportes históricos, funcionando de manera completamente autónoma sin conexión a internet.

#### 2.  Alcance funcional del sistema
El sistema se organiza en cinco módulos:
Inventario — alta, edición y eliminación de productos, con categoría, precio de compra/venta y stock.
Ventas — registro de ventas por producto y cantidad, con historial diario y mensual.
Gastos — registro de egresos del negocio, clasificados por categoría (arriendo, compras, servicios, insumos).
Ganancias — cálculo automático de ingresos, ganancia bruta, ganancia neta y margen, comparando el mes actual contra el anterior.
Reportes — consolidado histórico exportable, con totales de ventas, ingresos y ganancia por mes.
Una función transversal de escaneo de código de barras/QR agiliza el registro de productos y ventas desde Inventario y Ventas.
